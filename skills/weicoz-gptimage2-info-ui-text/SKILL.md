# GPT-Image-2 Info UI Text

目标：生成结构清晰、文字可读、界面可信的信息型 prompt，并显式提醒人工核查。

共享场景库见 `../weicoz-gptimage2-prompts/references/prompt-patterns.md`。

## 工作流

1. 判断输出类型：信息图、教学图、UI 截图、社交截图、手写/字体、漫画文字。
2. 固定文字：把必须出现的标题、标签、正文、数字、按钮、评论逐字写进 prompt。
3. 设计结构：模块、卡片、网格、步骤、导航、状态栏、气泡、层级。
4. 加质量约束：文字清晰、排版真实、信息不拥挤、图标统一、避免概念稿感。

## 默认策略

- 信息图：模块化分区 + 圆角信息框 + 标题层级 + 图标 + 浅色背景 + 留白。
- 教学图：步骤编号、箭头、局部放大、注意事项；提醒箭头和事实需核查。
- UI 截图：真实平台逻辑，状态栏/导航/控件/底栏齐全，避免手机外壳除非用户要求。
- 社交截图：头像、昵称、时间、评论、互动控件完整；提醒虚构/误导风险。
- 手写/书法：指定纸张、笔迹、墨迹、行距、自然瑕疵，不要电脑字体。
- 创意字体：文字作为主体结构，元素顺应笔画生长，避免贴图堆砌。

## 输出格式

```markdown
最终提示词:
[完整信息/UI/文字 prompt]

选择理由:
- 类型:
- 信息结构:
- 文字策略:
- 比例:

可选补充:
- [缺正文、平台、状态栏、数据来源等]

风险提醒:
- [文字/事实/箭头/社交仿真/高风险内容核查]
```

## 必须提醒

文字密集图不能把模型输出当最终事实。教育、医疗、急救、历史、考试、产品参数、价格、社交截图都要人工核查后再发布。
