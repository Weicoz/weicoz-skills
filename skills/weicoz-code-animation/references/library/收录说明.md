## 省略了什么，为什么

| 省略 | 原大小 | 原因 |
| --- | --- | --- |
| `示例/B6_.../Opus5.5_High.mp4` | 22M | 渲染结果可由源码重出，不值得进 git |
| `示例/B6_.../DeepSeek-V4.1-Flash_High.mp4` | 22M | 同上 |
| `示例/X7_.../ink-and-thunder.mp4` | 17M | 同上 |
| 三个 `截图_*.png` | 约 600K | 对话/出图截图，信息已由 md 说明覆盖 |
| `_统计.json` | 164B | 与 `scripts/build_index.py` 生成的 `../index.json` 重复，保留会两处漂移 |

因此 `说明.md` 与 `许可与来源.md` 里提到“示例含 mp4”的表述，在本库中对应的是**源码**。
要看成片，对 B6 的两个 html 用 `scripts/render_mp4.sh` 重渲即可；X7 只能当源码参考（见上）。

另外，`说明.md` 里指向 `示例/` 的相对路径在本库已失效——示例移到了 `../examples/示例/`。
查询风格请改用 `scripts/style_search.py`，不要按原作者说的“把整个文件夹丢给模型读”。

## 更新素材

1. 增删改 `风格提示词/` 下的 md（含新增静帧 jpg）。
2. 运行 `python3 scripts/build_index.py` 重建索引与目录。
3. 运行 `python3 scripts/build_index.py --check` 校验，会同时核对挑选页与正文的 ID 是否一致。
4. 若改了 `风格挑选.html`，重新生成时确保它仍内嵌 `<script id="data" type="application/json">` 结构；脚本依赖该结构取类别顺序。
