# 过程卫生

## 凭据不进输出

进程列表和环境会带出密钥。`pgrep -fl`、`ps aux`、`ps -E`、`env`、`printenv` 的输出可能含 API key，一旦打进会话就留在日志里。

- 查进程是否存在：`pgrep -q "<模式>"` 看退出码，或 `pgrep -f "<模式>" | wc -l`。
- 要看是谁：`ps -o pid,etime,comm -p <pid>`，只列字段，不列参数。
- 已经打出密钥：立刻告诉用户，建议轮换，不要复述密钥值。

## 等待后台渲染

- 渲染和长任务用 `run_in_background` 启动，等完成通知；不写 `until`/`sleep` 轮询。
- `pgrep -f "<模式>"` 会匹配到调用它的那条命令行本身，写成 `until pgrep -f xxx` 的等待循环永远不退出。要在命令里用，把模式写成 `[x]xx` 形式。
- 终止渲染：`pkill -f "<含输出文件名的完整模式>"`，再用 `pgrep -q` 确认。同一台机器上别的工程也可能有 remotion 进程，模式要带本工程的输出文件名。

## 渲染成本

- 画面和音频分开渲染：画面用 `--muted`，音轨用 `--codec=mp3`（不渲帧，快），再用 ffmpeg 封装。画面没变时音轨可复用。
- 带字幕版与无字幕版各渲一份无声画面，音轨按需混合。
- 只改了几个镜头，用 `scripts/render-shots.py`。
- 中间轮次用 `--scale=0.5` 看构图；字号和遮挡类检查才需要全尺寸。
