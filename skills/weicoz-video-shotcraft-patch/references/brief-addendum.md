# 简报补充：五个问题

video-shotcraft 的产品简报表没有这五项，缺了就会在成片后返工。每项先给推荐，再并入那 1–3 个提问，不单开一轮。

| 项 | 推荐 | 为什么要问 |
|---|---|---|
| 字幕烧录 | 有旁白的片烧录整句字幕，同时交 `.srt`；无旁白版不烧 | 字幕放到成片后补，会盖住已定稿的画面，要返工多个镜头 |
| 字幕安全区 | 1080p 下字幕条占 y≈946–1034（`bottom: 44px`，约 74 px 高）；所有文字、数字、标签、算式的最低点 ≤ y=900；水波和装饰可以在字幕条下方 | 安全区在分镜阶段定，实现代理才能一次做对 |
| 色系连续 | 整片单一色系。中途借用别的色系，先做「前一镜头末帧 + 该镜头 + 后一镜头首帧」的对比帧，用户看过才定 | 静帧对比图看不出相邻镜头之间的断层，成片里才暴露 |
| 素材 | 按镜头给建议再问：概念、数字、流程用手搭；要看到真实场景的镜头建议用素材，先找公开素材库（质量与合适度优先，可接受署名），没有合适的或需风格化再 AI 生成（途径届时再问） | 用不用素材影响画风和分镜；之后才问会让已定稿的镜头返工 |
| 配音语速 | 问「每分钟多少字」，写成数字；字数口径是去掉空白和标点后的字符数 | 语速决定每个镜头的帧数，中途改会让全部时间线重排 |
| 交付版本 | 默认一版：烧录字幕 + BGM（字幕另交 `.srt`，它不占渲染）。用户没提多版本就按默认，可以顺带问一句「要不要无 BGM / 无字幕版」；用户要了才渲 | 每多一个版本，每轮修复都要多渲一遍画面或音轨，渲染时间成倍增加。审查用的无字幕画面、分轨是检查件，不算交付版本，只在要跑对应检查时渲 |

## 写进 design-spec 的格式

```
字幕：烧录 / 不烧录；字幕条 y 范围：946–1034；内容最低点：900
色系：全片 <色系名>，借用：无 / <镜头>（已看交界对比帧）
素材：手搭为主 / 含素材（镜头：<s4、s7…>；素材库：Pexels、Pixabay、Unsplash、Wikimedia；BY-SA：不允许 / 允许；AI 生成：不用 / 用（途径：<届时确定>））
语速：<字/分钟>（口径：去空白与标点），引擎：<weicoz-zero-tts / edge>，声线：<声线>，倍率：<speed 或 rate 实测>
交付：一版（烧录字幕 + BGM）/ 另加 <无 BGM、无字幕…>（用户要求）
```

## 相关规则

- 分镜表里的「时间」列用实测旁白时长，不用字数估算。旁白合成之前的时间只是暂定。
- 分镜是给实现代理照做的规格：每个镜头写风格、用哪几种颜色、画什么、画多大、卡在哪个词上。用户说「好看一点」时，先换成这些具体条目再派单；只给形容词，代理只会往上堆光效。
- 两份稿子数字不同时，在简报阶段问清。画面上月入这类只计部分收入项的数字，必须用小字标明计入哪几项。
