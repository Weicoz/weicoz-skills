# weicoz-ui-pro

面向 AI Agent 的专业级界面设计方法（weicoz 自研免登录版）。
吸收 Pro 级设计工作流与审查规范，**彻底脱离账号登录、版本更新检查与远程付费积分生图**，适合团队内部共享与持续维护。

## 核心特性

- **默认单方向深化**：深入分析业务场景，默认推荐一个最适配的高完成度方案并深化，避免盲目多方案浪费 token。
- **留一处让人记住的地方（Signature Moment）**：把关键交互（动效、反馈、核心卡片）做到极致，其余界面保持克制与统一。
- **明确要求才做对比**：仅在用户要求比较时，才生成多风格同屏可交互对比页。
- **真实画面与 10 分制评审**：双端视口（Desktop 1440x900 / Mobile 390x844）取证，支持只读独立评审。
- **100% 免登录纯本地运行**：移除所有第三方账号校验与远程扣费，生图直接对接本地工具或免费 CC0 素材。

## 上游同步与更新

当本机已安装的 `oil-ui-pro` 有新版本特性时，可在本 Skill 根目录运行一键同步更新：

```sh
python3 scripts/sync_upstream.py
```
该脚本会自动对比上游文件，拉取更新并重新执行免登录脱钩转换。
