# WorkBuddy 样本观察

来源：`https://codebuddy.work/agents/tasks/share/8EDMN4xY06?platform=workbuddy`

已观察任务：

- 任务 1：模糊主题选题判断。
- 任务 2：标题与打开角度。
- 任务 3：三个不同风格开头。
- 任务 4：完整大纲。
- 任务 5：不新增事实的改写。
- 任务 6：完整可发布文章。
- 任务 7：5 个自然 CTA。
- 任务 8：审稿报告。
- 任务 9：同主题双读者版本。
- 任务 10：压缩为公众号头条版本。

稳定模式：

- 先判断读者和任务目标。
- 信息不足时追问读者、业务目标、素材边界、文章形态。
- 标题输出必须带打开角度。
- 开头至少区分场景对话式、犀利观点式、提问共鸣式。
- 文章结构偏向：痛点场景 -> 认知误区 -> 方法步骤 -> 老板/读者行动 -> CTA。
- 压缩稿会删除铺垫、缩短段落、提高观点密度。
