# Field Rules

## Template policy

- Keep the workbook template fixed.
- Do not add or remove columns.
- Do not move merged cells or summary rows.
- Only replace data inside existing cells.

## Data policy

- Sort records by `收款日期` ascending unless the user says otherwise.
- Leave `合同编号` blank when missing.
- Keep numeric values in two decimal places.
- Keep empty cells empty rather than filling placeholder text.

## Review policy

- Show a preview table before writing the final workbook when the user asks for confirmation.
- Verify the generated workbook by reopening it and checking row order, totals, and cell placement.
