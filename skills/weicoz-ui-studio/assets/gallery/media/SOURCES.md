## 衍生图

`story-key.webp`、`story-cool.webp`、`story-red.webp` 由 `vase.webp`（克利夫兰艺术博物馆 2025.127，CC0）缩放到 800px 宽后，按明暗与色相拆成墨版、石绿版、暖色版三层透明图，用于效果页的滚动套色叙事。只是示意分色，不代表原作真实的雕版分版。原作同为 CC0，衍生图随本项目的许可发布。

## 材质贴图

`pear-wood.webp`：Poly Haven「Angli Veneer」1K 漫反射贴图，作者 Jenelle van Heerden，CC0（https://polyhaven.com/a/angli_veneer ，许可 https://polyhaven.com/license ）。旋转 90°、缩放到 1024px 并略提亮，用作效果页刻刀格的版木。

`plate-key.webp`、`plate-cool.webp`、`plate-red.webp`：把上述三张衍生分色图依次叠在纸色底上，截取同一处香炉与果盘局部（400×250），用于效果页滚动叙事每一章的配图。
