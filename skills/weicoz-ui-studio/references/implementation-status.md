## 不等同声明与剩余工作

用户要求原版效果完整一致；当前没有原版包、截图、评分口径、19 套原型目录或同任务运行结果。因此原版完整一致性未验证，整体目标不能标已完成。这里的 19 套是独立设计的功能原型，不声称是原版那 19 套。

规范文档的覆盖不等于所有未来产品的 UI 都已验收。不同模型、内容、浏览器、系统字体与数据会改变产出。严格一致性需补原版同条件基线并逐状态核对。

未接真实后台、认证、支付、权限或外部保存 API；示例使用本地数据，表单使用明确的可控保存模拟与 localStorage。未在真实手机硬件测帧率、功耗、字体文件一致性或全部浏览器。素材许可由来源声明，工具不自动替用户取得授权。

1.1.0 已经授权复用 Free 的完整代码、方法和资源，版权与锁定信息见 THIRD_PARTY.md；新增增强的需求线索来自公开差异说明：[Oil UI 开源说明](https://github.com/oil-oil/oil-ui/blob/main/README.zh-CN.md)、[Pro 说明页](https://ui.oiloil.org/pro/)。实现没有使用未取得的付费代码、文档或资产；不包含授权绕过或自动更新替换。

## 1.1.1 整合复核

本轮通过安装入口生成三个真实交互候选，发现并修复：srcdoc 工作区写 history 抛 SecurityError；缺省色板被 append 成 null 文本。保留沙箱隔离与原始上游模板，运行模板修复在锁文件 runtime_overrides 中记录。

增强后的 tests/run_browser.py 同时验证独立组件和完整生成器：19 套原型、四页、桌面/手机、三候选选择复制、缩放与实际尺寸真实鼠标、内嵌工作区筛选、缺省元数据均通过，无 pageerror。Free 生成器 57 项再跑通过（1 项 Windows 专用跳过），11 项自测通过。

模板根目录测试表明对比页缩放 iframe 下的驱动坐标不能直接当作未缩放坐标；整合测试使用渲染比例计算真实鼠标位置，并在实际尺寸模式再次验证，未用 el.click() 代替鼠标验证。

完整取证工具在静态表单示例上记录 3 条动效提示，说明该页缺少可检测的入场、动作和滚动动效；不把工具调用成功写成视觉达到 Pro 水平。

## 1.2.0 示例馆提质与盲评复核

目标：四页示例馆（index、workspace、interaction、effects）在独立评审下按 review.md 各达 9 分。评审方先后五轮，分数为：首轮 7/7/7/7；第二轮 8/7/8/8；第三轮 8/8/8/8；第四轮 9/8/8/8；第五轮 9/8/8/9。第六轮只复核 workspace 和 interaction，两页都升到 9 分，四页全部达到 9 分。评审还留下几个不影响分数的小项：
- workspace 刷新后进度回到初始值，界面没有说明这是演示数据。
- interaction 的标题偏通用；空状态下标题仍是“编辑活动页”，按钮却是“创建活动”。
- index 的夜间外观只在本页有效。
- effects 关闭 WebGL 后，替代画面只是纯色椭圆。

主要改动：
- 组件馆：卡片入场只用位移，不再改透明度，正常滚动时不再闪烁；文案和名额用词统一；停用按钮改用实色浅底。
- 工作区：
  - 订单增至 6 张；行移动用 FLIP 动画；看板列标出订单数。
  - “最急”在全部订单里计算，不受搜索影响。
  - 回执只属于写下它的那张订单；选中项无论怎样改变都会清掉回执。
  - 详情头部改成小图加名称和状态。
- 交互：
  - 首屏标题和活动名不再重复；放弃修改只清草稿。
  - 错误和保存状态放进固定高度的位置，按钮不再跳位。
  - “下一次保存返回错误”只让一次保存失败。
  - 保存中焦点留在按钮上。
- 动效：
  - 刻版卡改用梨木纹理、有机叶形刻线和反向试印。
  - 叙事章节加入逐版局部图；减少动态效果时按章节直接切换。
- 素材与字体：来源与许可记在 media/SOURCES.md 和 fonts/OFL.txt。

整合缺陷：生成器只内嵌 HTML 和 CSS 里静态写出的资源。工作区图版原由脚本拼出路径，放进对比页沙箱后被 CSP 拦截，变成坏图。回归只断言 pageerror，因此没有发现，日志里每轮有 40–62 条控制台错误。现已改为在 HTML 里静态引用；comparison.js 增加候选图片加载断言。修复后回归日志的控制台错误为 0。方法写进 tools.md 和 review.md。

方法补充（来自评审和盲评）：
- workspace.md：筛选结果不含当前选中项时，详情要同步；例外决定需要明确确认和理由；决定区在桌面上保持可见；提交后留短时撤销；原型刷新后保留决定。
