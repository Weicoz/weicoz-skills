# 视觉、素材与精修

## 视觉语言

先定一个主角：内容、产品图、人物或关键动作。字体分标题、正文、数据三个角色；优先项目字体，中文逐字检查缺字和回退。把字号、行距、空间、圆角、边框和语义色落成少量变量；按内容的长短与密度调，而非给每块塞同样卡片。

颜色承担背景、文字、强调、状态的固定职责。必要正文对比度按 WCAG AA 检查；渐变不能承担唯一文字对比。首屏只突出一个主要行动，次级行动使用更轻的视觉。

正文保持易扫读的行宽。长中文、长名字、数字小数位、日期和图标一起看。小屏靠重排而非整体缩小；200% 缩放不失任务。首屏外的表格、底部动作、空错误状态沿用同一语言。

## 素材工作流

关键素材决定构图时先定素材再排版。用当前宿主的搜索/图片工具检索，保留搜索词、来源页、作者、许可、用途、原图尺寸和裁切焦点。素材分可发布、待核许可、仅参考；未确认许可不直接放进可发布资产。

按任务选照片、博物馆馆藏、科学工程图、真实贴图、生成插画、视频或 3D。材质需要 PBR 时核对 diffuse/roughness/normal 的色彩空间、法线方向与许可；不要把 JPEG 当法线。图中文字密集时优先真实 HTML/SVG 文本。生成图标明生成来源，品牌/身份参照保留用户明确特征。

对候选做带来源编号的联系表，视觉检查后选取；下载检查 MIME、完整解码、宽高与大小，避免 HTML 错误页伪装图片。记录到项目 SOURCES.md；不把参考图片许可当可分发许可。

## 实时 3D

场景确实需要旋转、交互光照或空间时使用项目已有引擎；仅预定镜头展示可用预渲染视频。预算先给纹理、draw calls、首帧和手机功耗；按真实设备测量。加载失败给静态海报，WebGL 丢失给替代信息；重要按钮在 DOM，不能只画在 Canvas。范例 `effects.html` 包含 WebGL 图形与 CSS 3D 折展，作为最小可运行起点。

## 精修与减法

去掉没有内容依据的渐变大标题、泛用三栏功能卡、徽章堆砌、同样圆角阴影、无意义数字和随机英文标签。保留品类需要的通用控件。比较 480px 缩略、100% 实际尺寸、全页、暗色/高对比和减少动态效果；一处更强，不代表每处都更强。
