# 视觉、素材与精修

完整视觉和素材流程先读 [视觉语言](free/visual-language.md) 与 [素材](free/media.md)，再读本文。真实素材默认使用 curate-media.mjs，而非只用本地图片清单。

## 视觉语言

先定一个主角：内容、产品图、人物或关键动作。字体分标题、正文、数据三个角色；优先项目字体，中文逐字检查缺字和回退。把字号、行距、空间、圆角、边框和语义色落成少量变量；按内容的长短与密度调，而非给每块塞同样卡片。

颜色承担背景、文字、强调、状态的固定职责。必要正文对比度按 WCAG AA 检查；渐变不能承担唯一文字对比。首屏只突出一个主要行动，次级行动使用更轻的视觉。

正文保持易扫读的行宽。长中文、长名字、数字小数位、日期和图标一起看。小屏靠重排而非整体缩小；200% 缩放不失任务。首屏外的表格、底部动作、空错误状态沿用同一语言。

## 素材工作流

关键素材决定构图时先定素材再排版。用当前宿主的搜索/图片工具检索，保留搜索词、来源页、作者、许可、用途、原图尺寸和裁切焦点。素材分可发布、待核许可、仅参考；未确认许可不直接放进可发布资产。

按任务选照片、博物馆馆藏、科学工程图、真实贴图、生成插画、视频或 3D。材质需要 PBR 时核对 diffuse/roughness/normal 的色彩空间、法线方向与许可；不要把 JPEG 当法线。图中文字密集时优先真实 HTML/SVG 文本。生成图标明生成来源，品牌/身份参照保留用户明确特征。

对候选做带来源编号的联系表，视觉检查后选取；下载检查 MIME、完整解码、宽高与大小，避免 HTML 错误页伪装图片。记录到项目 SOURCES.md；不把参考图片许可当可分发许可。

## 实时 3D

场景确实需要旋转、交互光照或空间时使用项目已有引擎；仅预定镜头展示可用预渲染视频。预算先给纹理、draw calls、首帧和手机功耗；按真实设备测量。加载失败给静态海报，WebGL 丢失给替代信息；重要按钮在 DOM，不能只画在 Canvas。范例 `effects.html` 的“墨洇楮纸”是一段全屏片元着色器：分形噪声扭曲距离场，干边与纸纤维都由同一套参数算出，减少动态效果时直接画终态，可作为最小可运行起点。

## 精修与减法

去掉没有内容依据的渐变大标题、泛用三栏功能卡、徽章堆砌、同样圆角阴影、无意义数字和随机英文标签。保留品类需要的通用控件。比较 480px 缩略、100% 实际尺寸、全页、暗色/高对比和减少动态效果；一处更强，不代表每处都更强。

精修时逐条核对这些常见失手：

- **说明压在标题上方就是眉标。** 分类、时长、日期这类小字放到标题下方，标题与它说明的内容之间距离最小（约 8px），与上文拉开。截图工具报“标题离上文比离下文还近”时，先查是不是这个原因。
- **组件从同一个产品与素材里长出来。** 多个组件、页面同屏时，先定一个产品世界和一组真实素材，再让配色、字体和图贯穿；每张图只出现在与内容相关的位置，比如商品卡放商品本身、详情面板放当前对象，而不是给所有卡片配图。
- **栅格按内容给尺寸。** 组件馆、仪表盘、作品集不用等宽三栏一排到底；重要对象跨两到三列，每张卡按自己的内容取高度（`align-items: start`）。不要把同一行拉成等高，矮卡片里会留下大块空白，一张卡展开时整行跟着变长。底面分两种：阅读型内容直接排在页面上，交互对象才装进卡片，滚动时能看出高低错落。
- **按钮分主次。** 一屏里实心主按钮只给推进任务的动作（购买、提交、保存）；收藏、关注、展开、下载用描边或文字链接。满屏同一种实心按钮，等于没有主次。
- **字体即概念。** 从品类自己的物质文化里找一种排字方式，让标题本身就是概念：书籍用题签，新闻用号外，药品用说明书，交通用时刻表。标题、主图、说明三栏并列只是排版，不是概念。
- **中文孤字。** 段落开启 `text-wrap: pretty`，标题用 `balance`；窄卡片里的长标题先缩短文字，再考虑调整栏宽。日期、金额这类片段整体不断行。
- **素材叠印。** 带纸底的扫描图做正片叠底时，先把纸色提亮到接近背景，再用径向遮罩淡出原图边缘，不能留下深色矩形或双重纸边。
- **暗色主题的继承。** 主题变量定义在 body 或容器上时，必须在同一元素上重新声明 `color`；只在根元素写 `color: var(--text)`，后代继承的是根元素算好的浅色值，暗色下会变成深底深字。切换主题后必须重新跑一次对比度检查。
