# 后台与工具的工作区

先问用户的工作对象、操作频次、上下文切换和比较需求，再选布局。

| 任务 | 布局 | 必验 |
| --- | --- | --- |
| 查找后处理单条记录 | 列表—详情 | 当前选择、筛选保留、后退、键盘、手机单栏 |
| 观察流转与优先级 | 看板 | 空列、溢出、键盘移动替代拖放、移动失败恢复 |
| 比较与批量操作 | 表格 | 排序、筛选、全选范围、分页、批量结果 |
| 创作与调参数 | 画布—检查器 | 选中对象、撤销、缩放、检查器滚动不带动画布 |
| 多步骤配置 | 步骤式工作区 | 已完成、当前步、校验、返回不丢输入 |

导航表示位置，工具栏表示当前对象动作，状态栏表示结果。三个区域职责清楚。仪表盘指标必须关联下一步行动；装饰数字不代替可操作记录。

把设计变量贯穿导航、表格、表单、图表和浮层：相同密度、边框、字体、选中态、错误态。用真实长数据检查完整页面，不能只美化首屏。

组件馆 `workspace.html` 提供列表—详情、看板、表格切换、搜索、状态筛选和键盘可用的推进状态按钮；它是本地数据范例，不包含认证、服务端分页或真实业务权限。
