# 组件打磨与 19 套原型

原型是独立示例，不是任何商业组件的原始代码。打开 `assets/gallery/index.html`，选择模板，展开其源码；复制 HTML 时同时带上 studio.css 与 cards.js，音频卡带 notes.wav、文件卡带 projects.csv。脚本只初始化页面存在的组件，支持单卡装配；同一页面多实例时把 id 与控制关系改成唯一值或接入项目组件实例。项目已有组件时用这些状态与构图原则改已有组件。

## 选择原则

卡片用于独立对象和局部操作。长篇故事、连续表格、强视觉内容优先连续排版。卡片内部先决定主内容、元信息、主动作，再决定边框和阴影。一个卡片只突出一个主动作。

先验收 idle/hover/focus/pressed/disabled/loading/success/error，再磨动画。必要信息不藏在 hover；组件高度不能靠固定裁切遮掉长内容。图像有替代文本，装饰图 aria-hidden。图表同时给文本摘要。

空间折展只在对象连续性有意义时使用；开启减少动态效果时直接展开。微抽屉要给显式关闭入口，展开按钮有 aria-expanded 和 aria-controls；完整模态任务改用 dialog。

## 精修检查

缩略看焦点与剪影；100% 看字体、行距、图标光学对齐、按钮基线和边界。删掉没有解释价值的眉标、标签、重复边框和套卡片；保留例外要说出任务依据。相同功能保持相同位置和反馈，不以动效掩盖等待。
