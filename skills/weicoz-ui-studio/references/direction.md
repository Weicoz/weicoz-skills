# 方向：先有产品，再有形式

以用户首屏要看什么、做什么确定信息骨架。浏览、购物、工作台优先直接展示内容；说服型页面才使用宣言式首屏。保留品牌、真实内容与业务权重。

## 找依据

看两三个同类产品的真实画面，记录其内容密度、导航、主视觉、字体比例、主操作位置与反馈；记下来源、视口、具体取舍。失败的链接换来源，不拿想象当观察。借鉴原则，重新写本产品表达。

北极星用一句可决策的话描述，例如“用户两步找到待处理订单；排版像一份清晰的交接单”。“高级、现代、好看”不足以决定布局。

## 方向卡

每个方向写：目标用户与主动作；首屏主角；内容骨架；字体角色；色彩分工；关键素材；一处记忆点；与标杆的区别；主要风险。最多一两个强势细节，其余服务内容。

需要比较时，让骨架、字体、色彩、主视觉至少两个维度明显不同。共用相同真实文字与数据；不能只换颜色。先做一屏，480px 缩略并排看明暗块、焦点和留白，再看实际尺寸可读性。

品牌或参考已定时保持其语言，在版式与主视觉关系上探索。单组件只围绕主动作深化，不为凑三版扩大范围。

## 按页面选骨架

- 内容型：搜索/筛选 → 高价值内容 → 详情；让内容首屏可见。
- 工具型：工作区导航 → 当前任务 → 结果/检查器；主操作贴近对象。
- 商品型：产品与价格 → 关键选择 → 购买 → 证据与约束。
- 说服型：具体结果 → 产品证据 → 使用路径 → 可信证明 → 适配对象与行动。顺序随用户决策改变，不强套固定营销模板。
- 展览/故事：视觉引子 → 主题线索 → 连续章节 → 到达终点；滚动叙事不能阻止跳转。

用户选定后保留反馈和理由，只做该方向的完整状态。拼合多个方向时检查字体、空间、控件语言是否仍一致。
