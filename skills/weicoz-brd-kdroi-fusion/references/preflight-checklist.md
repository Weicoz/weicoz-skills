# Preflight Checklist (10 分钟)

用于 Step 0 前快速筛掉高风险方向，减少“做完才发现不值得”的情况。

## A. 需求真伪（必须）

- [ ] 能回答“用户在什么场景搜这个词”。
- [ ] 能回答“用户当前替代方案是什么”。
- [ ] 能回答“用户为什么现在就要解决这个问题”。

若以上 3 项中小于 2 项，先不要继续。

## B. 竞争与切入（必须）

- [ ] 至少列出 3 个直接竞品（不是泛品类）。
- [ ] 能说出竞品共同短板（不是“我做得更好”这种空话）。
- [ ] 有明确切入点（价格/体验/细分场景/分发渠道之一）。

## C. 变现与成本（必须）

- [ ] 有可验证付费意愿线索（价格讨论、交易页、替代迁移）。
- [ ] 启动成本在预算内（默认 `< $500`）。
- [ ] 能描述“第一笔收入从哪里来”（渠道 + 产品形态）。

## D. 执行可行性（建议）

- [ ] 首版范围可在 2 周内完成 MVP。
- [ ] 部署和计费模型明确（避免隐性按量失控）。
- [ ] 目标市场、语言、支付方式一致。

## 快速结论

- 继续：A/B/C 三组都满足。
- 暂缓：任一组不满足，先补证据再进入 Step 0。
