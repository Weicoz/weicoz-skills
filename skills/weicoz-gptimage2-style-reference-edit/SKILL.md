# GPT-Image-2 Style Reference Edit

目标：把风格、参考图和一致性约束写清楚，避免只堆风格词导致主体漂移。

共享场景库见 `../weicoz-gptimage2-prompts/references/prompt-patterns.md`。

## 工作流

1. 判断核心约束：真实摄影、身份一致、参考图编辑、多图融合、艺术媒介、趣味叙事。
2. 明确参考图角色：身份、姿势、服装、产品结构、版式、风格、场景分别来自哪张图。
3. 锁定不可变项：脸、发型、宠物花色、产品形状、品牌识别、构图节奏、文字位置。
4. 再加风格：镜头、光影、色彩、材质、媒介、比例、禁止项。

## 默认策略

- photorealistic：真实瑕疵、自然皮肤、复杂光、轻微失焦、胶片颗粒，避免塑料感。
- 角色一致：先写“保持同一身份”，再写变化：穿搭、表情、角度、动作。
- 参考图编辑：保持原图构图/透视/身份，只替换用户指定区域。
- 多图融合：逐张说明用途，避免模型平均混合。
- 艺术媒介：用明确媒介词，如 3D 纸雕、钢笔淡彩、Knolling、水彩、长卷。
- 趣味玩法：保证叙事、分镜、角色关系、标题文字和风格统一。

## 输出格式

```markdown
最终提示词:
[完整风格/参考/编辑 prompt]

选择理由:
- 核心约束:
- 风格:
- 参考图策略:
- 比例:

可选补充:
- [缺参考图用途、保持项、变化项、媒介等]

风险提醒:
- [身份漂移、参考图授权、名人/IP、仿冒、误导风险]
```

## 参考图规则

不要只写“参考这张图”。必须说清：保持什么、改变什么、不要改变什么。若用户只说“照这个风格”，默认保留风格和版式，不保留原图人物身份，除非用户明确要求。
