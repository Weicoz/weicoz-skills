# 微信小游戏平台接入

所有 `wx.*` 调用只写在 `assets/scripts/platform/` 里，对外暴露与平台无关的接口（`save/load`、`share`、`showRewarded`）。web-mobile 预览时用同名空实现，让灰盒与试玩脚本不依赖微信。

数值取自微信官方文档（2026-04 版，2026-11 核对）。上线前重新核对，标“未确认”的项不得当成硬规则。

## 判断是否在微信里

```ts
import { WECHAT } from 'cc/env'
const wx = WECHAT ? (globalThis as any).wx : undefined
```

## 存档

- `wx.setStorageSync` / `wx.getStorageSync`：单个 key ≤ 1 MB，总量 ≤ 10 MB。web-mobile 用 `localStorage` 实现同一接口。
- 启动时集中做大量同步读写会拖慢启动：开局读一次存档到内存，变化时节流写回（如关卡结束、切后台 `Game.EVENT_HIDE`）。
- 存档写入带版本号（`{ v: 1, ... }`），读取时迁移旧版本；读不出时回到新档，不抛错。
- 文件系统（`wx.getFileSystemManager`）的本地缓存与用户文件合计 ≤ 200 MB，一般小游戏不需要。

## 分享

- 右上角“转发”默认不可点：启动时调用 `wx.showShareMenu({ menus: ['shareAppMessage', 'shareTimeline'] })`（`shareTimeline` 仅 Android Beta）。
- `wx.onShareAppMessage(() => ({ title, imageUrl, query }))` 设置右上角转发内容；游戏内按钮用 `wx.shareAppMessage({ title, imageUrl, query })`。图片比例 5:4。
- 官方接口没有分享成功回调。不要按“分享成功”发奖励；奖励改用激励视频，或只按“点了分享”给不影响平衡的小奖励。
- 通过 `query` 带关卡号等参数，启动时用 `wx.getLaunchOptionsSync().query` 读取。分享卡点开直接进那一关，不让朋友从第 1 关打起。
- 从推荐进来的玩家玩完就找不到游戏：首局结束后弹一次引导卡，箭头指向右上角 `···`，教玩家“添加到我的小程序”。

## 广告

- 开通流量主才能拉到广告，开通前要先完成微信认证。条件任一：累计 UV > 100（实践者 2026-11 报告，原为 500）且无刷粉与严重违规；开通游戏圈并有有效活跃且官方帖 5 篇；同主体已有小程序持续一个季度变现。开通前所有广告接口走空实现。
- 激励视频 `wx.createRewardedVideoAd({ adUnitId })` 是全局单例：开局创建一次，之后复用。
  - `onClose(res)` 里 `res.isEnded === true` 才发奖励（看完才算）。
  - `onError` 后用 `load()` 重拉；失败时按钮置灰或给替代路径，不卡住流程。
  - 每日观看次数有限（官方未给数值）。
- 插屏 `wx.createInterstitialAd`：每次调用新建实例；频率受限时 `show()` 返回 rejected Promise，捕获后跳过。只放在关卡间等自然停顿处。
- Banner 自基础库 3.5.5 起停止维护，用原生模板广告 `wx.createCustomAd`，刷新间隔 ≥ 30 秒。
- 广告播放期间暂停计时与音频，与切后台走同一套暂停逻辑。

**放置原则**（实践者数据：IAA 益智游戏激励视频约占收入 90%，插屏约 2%）：
- 激励视频只出现在玩家需要时：卡住、失败、道具用完、想要提示。刚进关、还没遇到困难时不弹。
- 道具不白送：每种道具开局少量（如 1 个），用完不自动补。送得越多，激励视频越没人看。
- 插屏能不放就不放：只在玩家主动停下时（回菜单）弹；新手前 15 关不弹；“下一关”“再来一次”永远不弹。
- Banner 或原生模板广告只放结算页底部，关卡内不放。
- 失败页把可选的激励视频按钮（复活、倒回、加时）并列，带 ▶ 标记，由玩家自己选。

## 隐私

- 用到个人信息相关接口时（用户信息、位置、录音、相机、写相册、剪贴板、加速度/陀螺仪、好友关系链与云存储等），必须在 MP 后台填写《用户隐私保护指引》，并做隐私授权：后台开启“隐私授权弹窗”，或自定义弹窗。
- 自定义弹窗：`wx.onNeedPrivacyAuthorization((resolve) => ...)`，用户点击后 `resolve({ event: 'agree' })` 或 `'disagree'`；`wx.openPrivacyContract` 打开协议。
- 完全不处理个人信息：后台确认“承诺未处理”即可。
- `__usePrivacyCheck__` 是否适用于小游戏：未确认。

## 性能

- 官方性能评分分启动、运行、网络三类。总启动耗时：优秀 1800 ms，建议 2200 ms，达标 2750 ms。内存、帧率阈值表：未确认。
- 降启动耗时：裁掉未用引擎模块（`weicoz-cocos-run` 的 `cocos-modules.mjs`），主包只留首屏，后续关卡放分包。
- 真机检查：微信开发者工具“真机调试”扫码；构建勾选输出 source map，线上报错看 MP 后台“WE 分析 → 性能质量 → JS 分析”。

## 后台资料与次数限制（2026-11 实测）

个人主体 MP 后台实测；到达上限后对应字段直接禁用：

| 资料 | 上限 | 说明 |
| --- | --- | --- |
| 介绍 | 120 字符，汉字算 2（约 60 汉字） | 到上限直接截断，先压文案 |
| 名称 / 简称 | 每年 2 次 | 微信认证通过后名称修改次数重置 |
| 头像 | 每年 5 次 | 一次改到位，别拿线上头像试风格 |
| 介绍、类目 | 每月 5 次 | 类目只能选 1 个，改类目要管理员扫码 |
| AppSecret | 每生成一次就重置 | 生成要管理员扫码，旧 Secret 立即失效 |

- 认证是备案的前置：没有完成微信认证，备案信息填不了。
- 备案完成前不改名称、不迁主体：与备案信息不一致要重新备案，先定名再备案。
- 单机游戏不需要服务器域名：不填 request 合法域名也能发布；只有联网功能（自建后端、排行榜服务）才要。
- AppSecret 换新前排变更窗口：正在用的服务会立刻拿不到 access_token。

## 凭据与代码上传（2026-11 实测）

- 变量按游戏加前缀：`<GAME>_WECHAT_APPID`、`<GAME>_WECHAT_UPLOAD_KEY_PATH`、`<GAME>_WECHAT_APPSECRET`，写在 `~/.zsh_secrets`；密钥文件放 `~/.config/weicoz-secrets/<game>/`（目录 700、文件 600）。别用无前缀的全局变量，多个游戏会互相覆盖。测试号 AppID 不进正式变量，用完删掉。
- 代码上传密钥（miniprogram-ci）：后台“开发管理 → 开发设置 → 小程序代码上传”。生成密钥要管理员扫码，文件只下载一次，不改名、不读内容、不贴聊天；编辑 IP 白名单要再扫一次码。
- 报错 `errCode -10008 invalid ip: <ip>`：运行上传的机器出口 IP 不在白名单。换网络、手机热点、代理都会让出口 IP 变；出口 IP 用国内查询服务取，别信境外服务（代理会给出境外出口）。不要图省事选“不限制 IP”；出口常变就固定用一台出口稳定的机器上传。
- miniprogram-ci 失败时会把压缩后的源码堆栈整段打印，上传脚本应 catch 后只输出 `errMsg`。
- Cocos 构建出的 `project.config.json` 里 appid 是 Cocos 默认值，开发者工具和上传都不认。构建脚本 `cocos-build.mjs --game <前缀>` 按 `<GAME>_WECHAT_APPID` 写入。
- 包体以 `--release` 为准：主包 ≤ 4 MB（实测 3.25 MB），大图放分包（subpackage）。
- 提审截图必须在微信里截（含右上角胶囊与游戏名）；网页端、开发者工具截图不行，体验版出来后用真机补拍。
- 商店文案和审核材料里不写关卡总数：关卡可无限扩展，写“逐关变难”，需要数字时与实际一致。

## 上线前检查

由用户在 MP 后台和开发者工具里操作，代理只整理清单与材料：

| 项 | 要求 |
| --- | --- |
| 主体与类目 | 个人主体可以发布，但不支持文化互动、角色、牌类类目。二级类目必须与实际玩法一致，否则驳回。 |
| 版号 / 软著 | 只靠广告变现（IAA）不要求版号；个人 IAA 实践者未被要求软著。名称含英文或“软件”字样、或涉及品牌与公众人物合作时要软著。开虚拟支付（IAP）必须有版号与软著。 |
| 认证 | 开广告前要微信认证：个人 30 元/年，企业 300 元/年。收入结算时平台代扣个税。 |
| 备案 | 先做小游戏备案，再做小程序备案，都要人脸核验，耗时较长，开发期就开始办。单机游戏备案未走完也可以先发布；排行榜、好友对战等联网功能要等小程序备案完成，所以首版先做单机。 |
| 名称 | 注册前查重；名称是玩家搜索词，要好记好搜（实践者一周 57% 收入来自搜索）。游戏内出现名称处与注册名一字不差，不加英文、不加副标题。 |
| 界面文字 | 全中文：首页英文名、弹窗英文小标题都会被驳回。 |
| 提审材料 | 游戏自审自查报告；主要场景、玩法说明、系统功能设计；游戏背景与主题；3 张以上在微信里截的截图（画面带右上角胶囊和游戏名）。代理可以起草文字，截图需要真机或开发者工具。 |
| 新游种子 | 首次发布后 90 天内可开一次平台推荐，只有一次：游戏打磨好、留存数据过关后再开。 |
| 适龄提示 | 必须设置；审核通过后平台在启动页展示。 |
| 防沉迷与实名 | 开虚拟支付才需自行接入；不开时由平台统一处理。 |
| 隐私 | 见上文“隐私”。 |
| 包体 | 主包 ≤ 4 MB，主包加分包 ≤ 30 MB，以 `--release` 构建为准。 |
| 回归 | `weicoz-cocos-run` 第 4 节的发版回归清单全部通过。 |

## 关卡统计

上线后按关看数据，用来校准机器人测出的难度。每关至少记：开始人数、通关人数、平均尝试次数、在该关之后不再回来的人数；可选记每步点击，用于回放玩家从哪步开始错。
- 埋点在前端统一一个 `track(event, props)` 出口，事件至少有 `level_start`、`level_clear`、`level_fail`（带原因与步数）。
- 上报通道：平台自定义分析（`wx.reportEvent`，小游戏可用性与配额接入前查官方文档）；自建后台属联网能力，受上文备案限制。
- 每出一批关卡，上线一周后对照预设难度，偏差大就调。
