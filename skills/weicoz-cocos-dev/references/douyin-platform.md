# 抖音小游戏平台接入

`tt.*` 调用同样只写在 `assets/scripts/platform/` 里，对外暴露与微信同一套接口（`save/load`、`share`、`showRewarded`）。web-mobile 预览时用同名空实现，灰盒与试玩脚本不依赖平台。

运行时判断：`typeof tt !== 'undefined'`。与微信共用一份平台层时，先判 `tt` 再判 `wx`。

## 资料与字数（2026-11 实测）

| 项 | 规则 |
| --- | --- |
| 简介 | 上限 60 字符，汉字算 2（约 30 汉字） |
| 详细介绍 | 上限 300 字符，汉字算 1（可写满 300 汉字） |
| 图标 | 600×600 px |

- 简介按“汉字算 2”的双字节口径计数，30 字就要收尾；先把一句话卖点压到 60 字符内再填，输入框到上限直接截断。
- 详细介绍按单字符计，300 字足够写玩法、目标用户、变现方式；两处口径不同，文案不能整段互抄。
- 图标另备 600×600，边界留白，缩小到列表尺寸后主体仍认得出。

## 资质：软著（2026-11 实测）

- 所有游戏都要软著，纯 IAA 单机也一样；只认中国版权保护中心的登记证书。
- 电子软著不能用于备案，按普通软著申请。
- 软著周期长，立项后就提交，名称与最终上架名一致；改名要和软著同步，否则备案对不上。
- 个人开发者可以发布抖音小游戏，广告变现（流量主）门槛是前一日 DAU > 50（2026-11 实测）。

## 备案与发布顺序（2026-11 实测）

```text
小游戏备案 → ICP 备案 → 提审发布
```

- 三步串行，前一步不通过后一步进不去；开发期就把软著和备案并行办起来。
- 小游戏备案要软著证书；ICP 备案按主体与域名办，没有服务器的单机游戏同样要走流程。

## 提审材料

- 自审自查报告：按平台模板填写后，在平台上点确认；不点确认视为未提交，审核不动。
- 详细介绍写满 300 字符，与实机玩法一致；提审截图用真机或开发者工具截，画面含游戏内 UI。
- 图标 600×600；界面文字全中文。

## 上线前检查

| 项 | 要求 |
| --- | --- |
| 主体 | 个人主体可发布；类目与实机玩法一致 |
| 软著 | 必须有登记证书，名称与上架名一致 |
| 备案 | 小游戏备案 → ICP 备案，两步都完成才能提审 |
| 广告 | 流量主门槛：前一日 DAU > 50 |
| 简介 / 详细介绍 | 60 字符（汉字算 2）／300 字符（汉字算 1） |
| 图标 | 600×600 px |
| 自审自查 | 平台点确认后才提交 |
| 包体 | 主包上限以后台提示为准，超限时先裁引擎模块（`cocos-modules.mjs`） |

来源：抖音开放平台小游戏文档与 2026-11 个人开发者实测（简介与详细介绍字数口径、软著与电子软著、备案顺序、流量主 DAU 门槛、自审自查需平台确认）。数值以抖音后台为准。
