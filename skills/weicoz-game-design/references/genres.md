# 品类速记

用户只给品类名时，先把它展开成下表的设计问题，再和用户确认取舍。表中是起点，不是必做清单。

| 品类 | 要回答的设计问题 |
| --- | --- |
| 竖屏打飞机 / 飞机大战 | 单指拖动还是点位移动；是否自动射击；敌机波次与 Boss 招式；判定框可读性；道具与火力成长 |
| 弹幕 | 弹幕图案可读性；最小逃生空隙；预警时长；玩家判定点大小；同屏子弹上限（性能） |
| 塔防 | 路径压力；塔位与建造点；索敌规则；伤害类型与敌人特性；经济与升级；拥挤时的可读性 |
| 肉鸽 | 单局结构；随机选择与流派组合；风险递增；失败原因可读；重开节奏；局外成长边界 |
| 合成 | 棋盘经济；合成规则；产出节奏；格子压力；目标清晰度；软失败状态 |
| 网格解谜（移出、拆线、推箱、连线） | 可解性保证；开局可走步数；死路率；提示机制；撤销是否允许；棋盘大小与缩放 |
| 排序 / 倒水 / 消除 | 颜色数与容量；空位数；初始混乱度；最短解步数；卡关时的道具 |
| 跑酷 / 躲避 / 下落物 | 车道或自由移动；速度曲线；预警时长；最小逃生空隙；奖励出现在风险之后多久；休息节拍 |

街机、躲避类在调难度前先定公平规则：同时出现的危险之间留最小逃生空隙，快速危险入场前有预警，重开和教学时刻不生成危险。难度靠在这些限度内收紧余量提高，不制造无解局面。
