# First Keyword Free Tools Cheatsheet

## Source Scope

这份速查表整理自一篇关于“用免费工具找到第一个关键词”的公众号文章，目标是把文章方法压缩成可重复执行的动作，而不是保留原文表述。

## Tool Split

- `Keyword Planner`: 负责给搜索量和广告竞争，优先看官方数据。
- `Ubersuggest`: 负责补 `KD`，因为 Planner 没有 SEO 难度。
- `AnswerThePublic`: 负责补真实问题和修饰词。
- `Google SERP`: 负责验证“这个词到底能不能切进去”。

## Default Thresholds For New Sites

- `Search Volume`: `50-1000 / 月`
- `KD`: `0-20`
- `KGR`: `< 0.25`
- `CPC`: `> 0.1` 视为正向信号

这些不是绝对真理，而是新站的默认起跑线。

## Formula Notes

### KDRoi

`KDRoi = Volume x CPC / KD`

适合回答：
- 这个词值不值得优先做？
- 同一批词里谁更接近“低竞争 + 有商业价值”？

### KGR

`KGR = allintitle_result_count / monthly_search_volume`

适合回答：
- 没有 KD 时，能不能先粗看竞争度？
- 这个词是不是明显太挤？

## Functional Keyword Bias

工具站优先看“功能型关键词”，因为这类词通常更接近具体任务和转化。

优先模式：

- `[功能] online free`
- `best [类别] tool`
- `[功能] tool`
- `how to [功能]`
- `[竞品] alternative`

常见母词：

- `Calculator`
- `Converter`
- `Generator`
- `Translator`
- `Editor`
- `Maker`

## 5-Minute Flow

### 1. Planner 扩词

- 输入 `seed keyword`
- 导出候选词
- 保留搜索量中段词，不要一开始碰超大词

### 2. Ubersuggest 查 3 个词

- 只查最像“可以直接开做”的 `3` 个词
- 按文章默认，免费版每天大约能查 `3` 次；如果产品规则变了，以当日界面为准

### 3. ATP 看真实限制条件

重点找：

- 按文章默认，免费版每天大约能查 `1` 次；如果产品规则变了，以当日界面为准
- `without login`
- `no watermark`
- `safe`
- `without losing quality`
- 其他体现顾虑、限制、摩擦的修饰词

### 4. Google 看首页结构

检查：

- 大站占比
- 是否有小站混排
- 是否有广告
- 是否已经被官方文档或强品牌完全吃掉

经验阈值：

- 前 `10` 名里如果有 `3` 个以上 `DR 80+` 强站，对新站通常偏难
- 如果你当前看不到 `DR`，就把官方站、超强品牌、大媒体、大平台结果当成“强站 proxy”

### 5. 只选 1 个

第一批关键词的目标是尽快做出页面验证需求，不是把选词清单做漂亮。

## Common Mistakes

- 只看搜索量
- 选太泛的词
- 不看广告和商业意图
- 不做 SERP 人工验证
- 一次开太多词，导致没有一个真正落地

## Recommended Output

最终至少给出：

- `1` 个最终关键词
- `2` 个备选词
- 每个词的搜索量、竞争度、商业信号、SERP 观察
- 为什么选它，而不是只说“分更高”
