# GPT-Image-2 Commercial Visuals

目标：把商业需求变成可交付视觉 prompt，重点保住产品准确、文案层级、品牌调性和平台规格。

共享场景库见 `../weicoz-gptimage2-prompts/references/prompt-patterns.md`。

## 工作流

1. 判断商业目标：卖货、品牌曝光、活动转化、平台素材、产品套图、品牌系统。
2. 提取固定信息：品牌名、产品名、卖点、价格、活动、平台、比例、参考图。
3. 选择版式：主图、详情长图、海报、轮播、套图、品牌板、公众号封面。
4. 写最终 prompt：明确文案、层级、画面主体、风格、材质、光影、禁止项。

## 默认策略

- 电商主图：产品居中、真实材质、干净背景、柔和阴影、卖点不拥挤。
- 详情页/长图：标题、卖点、成分/参数、场景、利益点、购买信息分层。
- 多平台广告：同一品牌视觉，按平台调整比例和信息密度。
- 品牌系统：先定义 Logo/包装/色彩/字体/应用场景，再生成展示板。
- 公众号封面：21:9，标题必须准确，人物/主题互动，浅色高级背景。

## 输出格式

```markdown
最终提示词:
[完整商业视觉 prompt]

选择理由:
- 商业目标:
- 版式:
- 风格:
- 比例:

可选补充:
- [缺品牌资产/价格/平台/参考图等]

风险提醒:
- [文案准确性、品牌仿冒、产品结构、促销信息核查]
```

## 商业风险

不要凭空编造价格、功效、赠品、资质、医学/护肤承诺。用户没给文案时，写“请替换为真实文案”。涉及真实品牌、名人、平台截图时提醒核查授权和误导风险。
