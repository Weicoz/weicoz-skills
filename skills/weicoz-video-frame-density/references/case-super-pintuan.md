16 镜 / 124.5 秒 / 1920×1080 深色商业讲解片。客户反馈「背景或者很多地方太空」。

## 样板改造（S05 主角镜）

手段：A 氛围层 + D 重构图。没有用素材视频。

| 项 | 改前 | 改后 |
|---|---|---|
| 内容覆盖率 | 2.9% | 6.4% |
| 中位亮度 | 0.044 | 0.086 |
| 信息层数 | 1（环） | 3（氛围 / 环 / 左右账本） |

具体改动：

- 氛围层四件套（网点 0.075 / 光带 0.085 / 数据雨 40 条 0.16 / 扫描列 0.07）+ 四角压暗 0.5
- 环 r 250→292，节点 46→50，中心币 88→96
- 左侧参与账本四行：团长 / 朋友 A / B / C，状态 待付 → 已付 → 已返 ¥19.90
- 右侧成团进度：25→50→75→100%，四格刻度尺 + 「还差 N 人」

## 过程中踩的三个坑

**坑 1：进度条写死节拍**
进度台阶写死 60/92/124，节点落位在 104/120/136。同帧出现「进度 75% / 账本 2 人已付 / 环上 1 个节点」三个矛盾数字。改成从 `NODE` 派生。

**坑 2：未到的行直接消失**
左栏只有 2 行时版面塌陷，右下大片空。改成 20% 透明度淡占位，四行始终在。

**坑 3：氛围层第一版太淡**
单层 0.02–0.04 的不透明度，中位亮度只从 0.044 升到 0.069，覆盖率 2.9%→4.9%。加一档后到 0.086 / 6.4%。**人眼看不见的不透明度等于没做。**

## 为什么不铺素材视频

背景里出现真人、写字楼、键盘，会和数字抢注意力，并立刻读作素材库模板。这支片的说服力来自「数字被认真算过」，一旦出现握手镜头，气质从「审计台」掉到「招商模板」。

素材视频只保留三个有场景语义的位置：S01（收银小票）、S09（钱包/券）、S14（农产品货架），全部重度遮罩：不透明度 8–15%、模糊 20–28px、局部遮罩。

## 全片改造结果

| 指标 | 改前 | 改后 |
|---|---|---|
| 中位内容覆盖率 | 4.2% | **12.7%** |
| 中位亮度 | 0.044 | 0.089 |
| 低于 6% 的镜头 | 13 | 0 |
| 码率 | 1.13 Mbps | 3.64 Mbps（源码对成片 PSNR 37.5–45 dB，网点完好） |

分镜处理：
- 12 个墨底镜头铺氛围层（逐镜 intensity 0.62–1.05，S11 本来就 13.3% 所以压到 0.62）
- 3 张纸卡在 `Stage` 里加印刷网线 + 纸纤维（纸卡从 98% 纯平单色变成有材质）
- 9 个极空镜头加第二层信息，覆盖率 2.2%→13.8% / 4.4%→13.7% / 4.5%→13.0% 等

## 素材视频的实测否决

原计划给 S01 / S09 / S14 三镜接可商用素材视频。实测 S14：

- 8.5% 不透明度 + 28px 模糊 → 肉眼不可见
- 16% + 22px → 一团暖色污渍，读作渲染故障

结论：深色数据片上的素材床是伪需求，撤掉。组件 `footage.tsx` 与素材、许可记录保留，供将来有真人叙事的段落使用。

## 投递时踩到的两个坑

**坑 1：飞书视频消息上限 30MB。** 改造后码率涨到 3.64 Mbps，成片 58 MB，`--video` 直接报 `234006 The file size exceed the max value`。
必须单独出一份投递副本（CRF 25 → 20.6 MB，对比母版 PSNR 45.9 dB）。母版留本地。
另：mp4 不能走 `--file` 消息（会报 `230055 上传类型与消息类型不匹配`），视频只能走 `--video` + 封面。

**坑 2：改一处，连带动三处。** 这次改 S10 的 `INCOMING` 节拍，连带要改音效表 4 条 cue；
改字号只改了 `fontSize:` 声明，漏了组件 `size={}` 属性 21 处，被审核抓出「文档说最小 26px，实测 18px」。
**结论：任何"统一改字号"都必须同时 grep `fontSize:` 与 `size={}` 两种写法。**

## 客户决策点

样板交付时给客户三个选项：

1. 背景再浓一档 / 再淡一档
2. 左右两栏的数值字比主体亮，是否压暗
3. 主体节点的纯黑圆是否要加人形符号

客户回「可以，继续」，按全片方案推进。
