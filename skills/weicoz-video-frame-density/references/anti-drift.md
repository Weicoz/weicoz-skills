# 反漂移规则全文与历史事故

画面改造会同时改动几十个时间点。不做单一事实源，下一版必错，而且错得很隐蔽——审的人看的是旧状态，改的人以为已经改了。

以下六条全部来自实战事故。

## 1. 字幕断行表不得存文案

**事故**：断行表里存的是手抄的整句文案，改旁白时只改了稿子和配音。断行表优先级更高，于是成片字幕一直在念已经被删掉的「所以我们做四件事：毫秒分润，百万并发…」。审核抓出来时，片子已经交付过一版。

**根因**：同一段文字存在两份副本，改一份不改另一份。

**修法**：断行表只存整数位置，文字一律从旁白取。

```ts
export const CAPTION_BREAKS: Record<string, number> = { u15: 14 };

export const captionText = (id: string, text: string): string => {
  const at = CAPTION_BREAKS[id];
  if (!at || at <= 0 || at >= text.length) return text;
  return text.slice(0, at) + "\n" + text.slice(at);
};
```

**校验**：断行位置必须 < 句长；落在标点后；不得把词劈成两行（事故：「团长八个点，三个成员各两个，推 / 荐人三个」）。

## 2. 第二层信息的时间必须从动作常量派生

**事故**：给主角镜加右侧进度条，台阶写死在 rel 60/92/124。主体节点的落位在 104/120/136。结果是「进度显示 75%，左侧账本只有 2 人已付，环上只有 1 个节点点亮」——同一帧三个数字互相矛盾。

**根因**：新加的信息层复制了旧的节拍数字，没有跟着主体一起派生。

**修法**：

```ts
// 错
const step1 = seg(frame, 60, 22);
// 对
const step1 = seg(frame, NODE, 14);
```

**校验**：把镜头时长压缩或拉长后重新渲染，第二层信息必须仍然同步。

## 3. 改画面后必须重钉音效

**事故 A**：S11 封顶线在 rel 230 落定，音效 cue 还在 rel 268。晚了 1.23 秒，落在完全静止的画面——只响不砸。

**事故 B**：整镜时长从 273f 压到 153f，画面节拍全变，音效表没动。免单 bell 比队首飞出早 17 帧，第 4 个新订单没有音效。

**修法**：改完动作帧，同步改音效表该镜全部 cue 的 `from`，然后用互相关实测。

**实测方法**：

```bash
# 1. 抽无 BGM 版音轨
ffmpeg -i out/promo-nobgm.mp4 -ac 1 -ar 48000 -f s16le - > /tmp/mix.raw
# 2. 与音源 wav 做归一化互相关，找峰值位置
# 3. 报「实测起音帧 vs 目标帧」偏差
```

偏差 ≤ 2f 合格。同时注意输出偏移常量（AAC priming），实测值应与常量吻合，不吻合说明管线另有漂移。

## 4. 文档帧号从时间轴生成

**事故**：`storyboard.md` 的手写表格同步过一次，但只同步了时间轴表，逐镜区间、转场帧、验收帧、能量曲线全是旧值。同一份文档第 50 行说「整画面震动 2px」，第 341 行说「震屏已撤销」，自相矛盾。

**修法**：所有帧号从 `timeline.ts` 生成或核对。审查时同时核三处：文档表格、代码常量、成片实际。

**事故**：README 写「17 个镜头」「89 条 cue」，实际 16 镜 / 87 条，同一文件第 68 行又写 87 条。

## 5. 审查帧必须从成片抽

**事故**：审查员基于 `out/review/` 判 PASS，但审查期间源码被改、成片被重渲，`out/review/` 还是旧版帧。PASS 结论作废。

**修法**：

```bash
# 对，从成片直接抽
ffmpeg -ss <秒> -i out/promo.mp4 -frames:v 1 out/review/S05-peak-f859.png
# 错，从源码渲染
npx remotion still src/index.ts Comp out/review/S05.png --frame=859
```

审查开始前先让审查员用 `ffprobe` 确认成片版本（帧数、时长），不符就停止。

## 6. 主物与旁白必须同帧对齐

**事故**：旁白说「金币不能提现」时画面是券；旁白说「券」时画面还是金币。翻面动画提前了 22 帧。

**事故**：旁白说「差了十五倍」出口时，屏上数字还停在 12×。计数在旁白念完才落定。

**修法**：主物切换（金币→券、数字落定）必须落在**说出它的那半句之内**，不能等整句念完。

**校验**：逐句取中点抽帧，看主物与字幕是否指向同一件事。

## 附：一次典型的漂移链

改旁白 → 忘了断行表 → 字幕念旧句
       → 忘了重钉音效 → 音效错位
       → 忘了重生成文档 → 文档帧号过期
       → 从源码渲染审查帧 → 审的是旧状态

四处独立，但都源于同一件事：同一个事实存在多份副本。
