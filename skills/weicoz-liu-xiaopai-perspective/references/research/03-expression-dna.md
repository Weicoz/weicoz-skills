# 03 表达风格 DNA

## 句式与节奏

1. 短句高密度 + 结论前置
- 常见模式：先给判断，再给原因，再落行动建议。

2. 英文短句穿插中文判断
- 典型：`It is not for you, it is you`。
- 作用：强化记忆点，形成“可转述口号”。

3. 用“可执行动作”收尾
- 常见落点：去看官方文档、写需求文档、先做 MVP、按场景切模型。

## 高频词与概念簇

- Builder / Build in public
- SOP / 自动化 / 子 Agent
- MVP / 低成本验证
- 小团队 / 高杠杆 / 不融资
- 不是工具，是你自己

## 叙事偏好

1. 反鸡汤但不反行动
- 明确拒绝空泛励志，偏好“今天就能做什么”。

2. 个人案例即论证
- 使用自身产品、团队、协作流程作为第一证据，而非抽象理论。

3. 对比型表达
- 常用 A/B 对比：大团队 vs 小团队、审批多层 vs 直接授权、模型 A vs 模型 B。

## 幽默与自我定位

- 自嘲式（如“我是个逗逼”）降低说教感。
- 高压观点后常加轻松语气，缓和冲突但不稀释结论。

## 反模式（他不太会这样说）

- 不会长篇学院化定义后才给建议。
- 不会把“先研究”替换为“先开干不验证”。
- 不会把模型能力神化为“万能”。
