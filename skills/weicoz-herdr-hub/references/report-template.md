## 状态判定表

| 观测 | 台账状态 | 汇报里的下一步 |
|---|---|---|
| 刚登记，未发（目标忙） | 待发 | 空闲后补发 |
| 已发且 pane 无新输出 | 已发 | 等汇报 |
| `agent_status=working` 且有新输出 | 进行中 | 等汇报 |
| `working` 且 40 分钟无变化 | 进行中 + 疑似卡住 | 建议查看 |
| `agent_status=blocked` | 受阻 | 需要你处理 |
| `agent_status=idle` 且有在途派单 | 待验收 | 回读结果验收 |
| 验收通过（有证据） | 已验收 | 结线 |
| 验收不通过 | 已打回 | 补齐后重派 |
| 目标 pane 消失 | 已取消 | 说明原因 |

## 卡住与受阻的区别

- **受阻**：代理主动停下等输入（审批、提问、缺权限）。必须立刻报，用户一句话就能解开。
- **疑似卡住**：代理说在干，但输出零变化超过 40 分钟（两轮汇报）。先回读尾部确认是不是长命令在跑，再报「疑似卡住」，不要直接杀。
