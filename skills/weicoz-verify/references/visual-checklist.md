# 联系图视觉巡检清单

验证脚本全部通过后，看拼好的联系图，按下面逐项找问题。当前模型不能看图时，用能看图的工具把联系图转成文字后判断；仍无法判断的写“视觉巡检：未验证”，交给用户。

- **残留**：该消失的元素（遮罩、旧内容、弹窗、加载态）还在。
- **遮挡与重叠**：文字压在可点区域、新旧内容重叠、关键元素被刘海或固定栏挡住。
- **文字**：截断、溢出按钮、字号过小、中英文或多语言漏翻译。
- **对比度与可读性**：可点与不可点分不清、遮罩压暗了关键信息。
- **尺寸极值**：最小和最大视口各看一张（手机竖屏、桌面宽屏）。
- **空态与错误态**：没数据、加载失败时有明确提示，不是空白页。
- **风格一致**（项目有设计规范时）：配色、按钮、字号、间距与规范一致；主操作最显眼。没有设计规范时写“尚无风格规范”，不能把默认样式当通过。

每发现一类问题，同时加一条脚本断言（如元素可见性、数量、文本内容），让同类回归以后不看图也能抓住。
