# 项目 AGENTS.md「验证约定」模板

复制到项目根目录 `AGENTS.md`，替换尖括号内容。只写代码和配置里查不到的东西；12 行以内。

```markdown
## 验证约定

按 `weicoz-verify` 执行。

- 状态：<待用户确认 | 已确认>

- 适配器：<cocos | web | 自建>
- 秒级检查：`<如 pnpm typecheck、pnpm lint>`
- 快检：`<一条命令>`
- 全检：`<一条命令>`；阶段门与合并前各跑一次
- 验收时运行器命令都带 `--base <基础分支>`（如 `... --quick --base main`），评分配置改动才会被发现
- 门禁项：<合并前必须过的检查，如包体上限、协议样例、部署环境变量契约>；必须并入全检命令，不得另列漏跑
- 功能地图：`tests/e2e/FEATURES.md`
- 目标环境：<微信开发者工具 / 生产构建 / 部署地址>，需要用户的步骤：<如开服务端口、登录>
- 高风险目录：<路径；改动交独立审查>
- 禁改目录：<路径；方案未允许时列为阻塞>
- 审查标准：`<CODING_STANDARDS.md / REVIEW.md>`，从基础分支 `<main / develop>` 读
```

字段缺失时按 `weicoz-verify` 默认规则执行。快检或全检命令还没有输出结论行时，在该行后注明“无结论行，按退出码判断”。
