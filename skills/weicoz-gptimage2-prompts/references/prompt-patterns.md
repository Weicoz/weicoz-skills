# GPT-Image-2 Prompt Patterns

证据来源：`awesome-gptimage2` 仓库 HEAD `ff9bda38462c039417b979dc757e65c4a153ea66`；中文 README 主体、英文 README、`data/latest-prompts.json` 35 条 X 数据、中文站 `SUPPLEMENT_PROMPT_CARDS`；APPSO 与甲木未来派公众号正文可读；AI新榜公众号不可读，只使用仓库摘录。

## 通用五要素

`[任务类型] + [主体描述] + [风格定义] + [技术参数] + [输出规格]`

实际写 prompt 时补齐：

- 任务：生成、编辑、复刻、迁移、扩展、批量系列。
- 主体：人、产品、品牌、信息主题、界面、场景、参考图。
- 文字：精确写出必须出现在图里的文案，不要只说“加促销信息”。
- 风格：媒介、时代、平台、审美、真实度。
- 技术：构图、镜头、光影、材质、色彩、景深、纹理。
- 输出：比例、清晰度、平台限制、禁止项。

## 场景库

### 商业视觉

- 电商详情页：产品主图、卖点模块、价格、赠品、成分、使用场景、品牌故事。
- 白底精修：保持产品形状准确，重打光，白底，柔和阴影，市场主图质感。
- 多平台广告：同一品牌扩展抖音弹窗、小红书种草图、Instagram 轮播、活动主视觉。
- 品牌海报：新品上市、品牌入驻、论文宣传、书封、K-POP、T 恤宣传。
- 公众号封面：21:9，人物/主题互动，标题清晰，浅色高级背景。
- 品牌套件：Logo、包装、海报、周边、字体板、应用展示板。

### 信息/UI/文字

- 信息图：模块化分区、圆角信息框、标题层级、图标、浅色背景、留白。
- 教学图：步骤、箭头、编号、注意事项；精确箭头需人工核查。
- UI 截图：状态栏、导航、控件、真实间距、真实平台逻辑，不要 Dribbble 概念稿感。
- 社交截图：微信朋友圈、微博热搜、TikTok、X 主页、GPT 对话；注意仿真和误导风险。
- 中文文字：直接给完整文案；适合海报、菜单、手写、书法、漫画气泡、多语言排版。
- 字体设计：文字本体作为画布，融入城市/文化/场景元素，避免拼贴堆砌。

### 风格/参考/编辑

- 真实摄影：`photorealistic`、35mm、胶片颗粒、自然瑕疵、真实光影、生活切片。
- 参考图编辑：保持主体身份、产品结构、版式节奏或场景透视，只替换指定内容。
- 角色一致性：锁定脸部、发型、比例、服装基调；再生成穿搭、角度、表情、贴纸。
- 多图融合：明确每张参考图承担什么角色：人物、姿势、风格、场景、构图。
- 艺术媒介：3D 纸雕、Knolling、水彩、钢笔淡彩、手绘涂鸦、暗黑插画、中国长卷。
- 趣味玩法：四格漫画、朋友圈整活、电影海报、游戏整活、猫咪武侠、360 全景。

## 自动风格选择

- 卖货/品牌：商业摄影、轻奢、干净电商、真实产品光、明确卖点层级。
- 知识解释：高级百科图鉴、模块化知识卡、浅色背景、可收藏信息图。
- UI/社媒：真实截图、生产级 UI、平台默认控件、自然瑕疵。
- 摄影：photorealistic、纪录片、35mm 胶片、自然光或复杂混合光。
- 角色一致：角色设定表、贴纸 sheet、杂志封面、穿搭 Lookbook。
- 艺术：优先媒介词，而不是泛泛“好看”：纸雕、水彩、Knolling、长卷、crayon。

## 用户指定风格

用户指定风格时不要替换，只补齐：

- 主体和动作。
- 构图和镜头。
- 光影、材质、色彩。
- 文字内容和层级。
- 比例和禁止项。

## 常用比例

- `1:1`：头像、产品主图、社交图。
- `3:4`：海报、信息图、插画。
- `9:16`：手机壁纸、竖版长图、短视频封面。
- `16:9`：横向截图、视频封面、演示图。
- `21:9`：公众号封面、电影感横幅。
- `3:1`：全景、长卷、超宽横幅。

## 风险和局限

- 文字多时必须给准确文案；完成后人工核查。
- 信息图和教学图的事实、箭头、步骤必须人工核查。
- 参考图身份一致性不是绝对稳定；提示词要明确“保持不变”的部位。
- 社交截图、名人、新闻梗图可能误导，需加“虚构/概念图”边界。
- X 数据中“prompt in comment/未展开”的条目只能作趋势信号，不能当完整 prompt。
