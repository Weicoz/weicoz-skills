# GPT-Image-2 Prompt Router

目标：把用户的模糊图像需求变成可直接给 GPT-Image-2 使用的提示词，并给出选择理由、缺失信息和风险提醒。

## 先判类型

把需求路由到一个主类型：

- 商业视觉：电商、产品图、广告、品牌、海报、营销物料、公众号封面。复杂商业任务可建议继续用 `$weicoz-gptimage2-commercial-visuals`。
- 信息/UI/文字：信息图、中文长文字、教学图、UI 截图、社交媒体截图、手写、字体、多语言排版。复杂文字和界面任务可建议继续用 `$weicoz-gptimage2-info-ui-text`。
- 风格/参考/编辑：真实摄影、参考图编辑、角色一致性、多图融合、风格迁移、艺术创作、趣味玩法。复杂参考图任务可建议继续用 `$weicoz-gptimage2-style-reference-edit`。

如需场景库，读取 `references/prompt-patterns.md`。不要把其中社区案例当成 OpenAI 官方能力声明。

## 输入补全

若用户没给全，不要卡住；用合理默认值，并把缺口列出来：

- 用途/平台：默认“通用可发布视觉”。
- 主体：从用户描述中抽取；没有主体就先问。
- 文字：用户没给时不要编造营销文案；可写“无固定文案”。
- 风格：用户指定则保留；未指定则按类型自动选。
- 比例：商业海报/信息图默认 3:4；手机/小红书/故事默认 9:16；公众号封面默认 21:9；产品主图/头像默认 1:1；横幅默认 16:9。
- 参考图：若用户提到“保持人物/产品/版式/风格”，在 prompt 中明确“参考图约束”。

## 输出格式

始终中文输出这 4 段：

```markdown
最终提示词:
[可直接复制给 GPT-Image-2 的完整 prompt]

选择理由:
- 类型:
- 风格:
- 比例:

可选补充:
- [缺失但能提升结果的信息]

风险提醒:
- [文字准确、事实准确、身份一致性、版权/仿冒、高风险内容等]
```

## Prompt 骨架

生成最终提示词时使用这个顺序，不必显示字段名：

1. 任务动作：生成/编辑/复刻/扩展。
2. 主体和场景。
3. 必须出现的文字和信息层级。
4. 风格、媒介、构图、色彩、光影、材质。
5. 参考图处理和一致性要求。
6. 比例、清晰度、输出规格。
7. 禁止项和质量标准。
