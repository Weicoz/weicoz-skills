# 安装轨道

## Greenfield（空仓或几乎无规范）

按目标选择必要文件；只有明确要求完整同构时才装完整地图。栈先查上下文和文件，关键未知才问。没有业务代码时只写已确定约束，不强凑宪法条数。

## Brownfield（已有代码，规范少或不统一）

1. 盘点 + 挖宪法。
2. 仅在本次用户明确要求 Clawith 同构时完整落盘；否则复用现有结构，仅补必要缺项。
3. 目录级 `AGENTS.md` 只写真实边界清晰的子系统。
4. arch-guard：新违规 VIOLATION；历史债 WARNING，并在宪法注明「存量豁免 / 新代码必须遵守」。
5. 已有 OpenSpec：默认沿用；明确授权迁移后才切换入口。

## Resync（已初始化，规范要跟上代码）

二次进入已装过本 OS 的仓：走 `references/align-resync.md`。

- 只审查：盘点、对比、分类、报告。
- 已要求同步或优化：完成盘点后直接写入范围内无冲突的更新；用户限定 ID 时尊重限定。
- 不为每个新模块目录自动创建 `AGENTS.md`。新边界只出现在报告的建议项里。

## 与存量规格系统的关系

| 存量 | 安装后 |
|---|---|
| OpenSpec `openspec/` | 默认沿用；明确迁移时保留为档案 |
| superpowers plans/specs | 默认沿用；明确迁移时保留为档案 |
| ADR | 继续追加；宪法引用编号 |
| 根 README 开发说明 | 不删；AI 入口改到 `AGENTS.md` |
